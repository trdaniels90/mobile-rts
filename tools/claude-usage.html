Every Claude Code session on this repo sends its token counts to Supabase when Claude finishes a turn (the Stop hook in .claude/settings.json). Cache reads are the context Claude re-reads each reply and cost about a tenth of fresh input; output and cache writes are what grow the bill fastest.
